# L'Impact — site

Site statique prêt à publier.

## Fichiers
- `index.html` : structure du site
- `style.css` : design responsive
- `script.js` : vidéos, filtres, recherche et lecteur
- `assets/logo-impact.png` : logo fourni

## Ajouter tes vidéos
Dans `script.js`, modifie uniquement les champs `videoUrl` de `VIDEOS`.
Ils doivent être des liens directs vers les fichiers vidéo, par exemple un `.mp4` ou `.webm`.

Exemple :
`videoUrl: "https://ton-domaine.fr/videos/mon-reportage.mp4"`

Le site peut être déployé directement sur Netlify, GitHub Pages ou Vercel.
